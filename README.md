# Gestión de Biblioteca

Sistema de gestión de inventario de libros desarrollado en C#, con persistencia en base de datos SQLite y exportación de reportes a Excel.

## Funcionalidades

- Registro de libros (título, autor, categoría, cantidad)
- Consulta del inventario completo
- Registro de préstamos y devoluciones
- Eliminación de libros
- Exportación del inventario a un archivo Excel (.xlsx)

## Tecnologías utilizadas

- C# (.NET)
- SQLite (Microsoft.Data.Sqlite)
- ClosedXML (generación de reportes Excel)

## Cómo ejecutar

1. Clonar el repositorio
2. Abrir la solución en Visual Studio
3. Restaurar los paquetes NuGet (Microsoft.Data.Sqlite, ClosedXML)
4. Ejecutar el proyecto (F5)

## Aprendizajes

Este proyecto fue desarrollado como parte de mi portafolio para aplicar conceptos de programación orientada a objetos, acceso a bases de datos y generación de reportes en un caso de uso real de gestión de inventario.
